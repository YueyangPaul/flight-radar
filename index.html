扫描城市

只有仓库主人能改城市列表。修改会用你的 GitHub 令牌直接写进仓库里的 cities.json，令牌只存在这台设备的浏览器里，不会上传到别处。
  1. 打开 GitHub 新建细粒度令牌。
  2. Repository access 选 Only select repositories，只勾这个网站的仓库。
  3. Permissions → Repository permissions → Contents 选 Read and write，生成后复制过来。

零请假怎么算

去程须周五首都机场 21:15 及以后、大兴 22:00 及以后起飞，或周六出发；更早的周五航班一律算请一天假。返程 22:30 前落地正常，22:31 到次日 00:30 降一级，更晚的排除。请一天假的组合还要比同周末零请假组合便宜（国内 ≥200 元、国际 ≥500 元，且都 ≥20%）才算低于阈值。

价格是什么价

国内用携程列表页的「往返总价起」再加机建燃油约 280 元推算，国际直接用「往返含税价起」。都是列表页起价，没有进订单页核验，下单前以携程实际价格为准。热力图是低价日历接口的周五去程 + 周日回程单程最低价相加，不看起飞时刻，只用来挑要精查的周末。

阈值和城市

每个目的地按提前期分三档（0–60、61–180、181–365 天），用最近 60 天日历样本算收缩后的 P20，样本不够时用冷启动阈值。新加的城市先用默认阈值，几天后自动换成动态阈值。城市列表改动在下一次每晚扫描（约 22:00）时生效。
